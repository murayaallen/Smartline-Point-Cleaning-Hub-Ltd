# Smartline Point Cleaning Hub Ltd

Client project: website, brand identity and sales documents for Smartline Point
Cleaning Hub Ltd (Nairobi) — commercial, residential and post-construction
cleaning, and landscaping, trading since 2018.

Live domain: **https://smartlinepointcleaning.co.ke** · deploy steps in `RUNBOOK.md`.

## The website — `site/`

Zero-build static site: hand-written CSS and vanilla JS, pages generated by
Python and committed, so the server only ever receives finished files.
8 content pages + thank-you, privacy, 404 · Apache `.htaccess` (HTTPS, one
host, clean URLs, CSP, HSTS) · PHP enquiry handler (honeypot, time trap,
per-IP rate limit, customer copy) · LocalBusiness / Service / FAQ / Breadcrumb
JSON-LD · sitemap, robots, manifest, `security.txt`.

```bash
python build_assets.py [--force]   # fonts, icons, logo, seal, WebP images, share cards -> site/assets
python build_site.py               # pages + server files, then verify() — fails loudly on any defect
python make_upload.py              # dist/smartlinepointcleaning.co.ke-upload.zip (gitignored)
python make_pages.py               # dist/pages — the GitHub Pages preview (CI publishes it to gh-pages)
python serve_local.py 8765         # local preview that behaves like the live .htaccess
node tools/qa_browser.cjs <out>    # browser QA, 11 pages x desktop + phone, plus interactions
```

| File | What it is |
|---|---|
| `site_layout.py` | **Layout and copy, single source of truth** — pages, sections, services, SEO, clients |
| `site_content.py` | Contact details, FAQ, standards, privacy text, image crops; switches for logo, GA4, prices |
| `build_assets.py` | Mona Sans instanced from `build_cache/`, grain tile, icon sprite, logo/seal SVG, graded WebP srcsets, share cards |
| `logo_original.py` | The client's own logo lifted as exact vector from `smart.pdf` (shading stops included) + their Gotham Black wordmark |
| `build_site.py` | Renders every page and server file; `verify()` checks HTML, links, anchors, SEO lengths, CSP, budgets |
| `site/assets/css/main.css`, `site/assets/js/*.js` | Hand-written v2 design system and motion engine (loader, squeegee hero, split text, scrub, pinned rail, scrollytelling, marquees, view transitions, forms, consent) |
| `make_upload.py` | Packages `site/` for `public_html` and checks the zip |
| `make_pages.py` + `.github/workflows/pages.yml` | GitHub Pages preview at https://murayaallen.github.io/Smartline-Point-Cleaning-Hub-Ltd/ — prefixed paths, noindex, form shows a preview note; republished on every push to main |
| `tools/qa_browser.cjs` | puppeteer-core + installed Edge; exits 1 on any console error, overflow or broken interaction |
| `RUNBOOK.md` | Build, QA, first deploy, live checks, Google set-up, maintenance |
| `CLIENT-REVIEW.md` | What the client must approve or supply; none of it blocks launch |

Plain `python`, not `python -I` — the scripts import `brandkit` from this folder.
Document fonts load from `C:/Windows/Fonts` (Segoe UI, Bodoni MT, Copperplate Gothic).
Source photographs (`media/all`, `media/incoming`, `media/real`) are gitignored;
`build_assets.py` needs them only when images are re-encoded.
