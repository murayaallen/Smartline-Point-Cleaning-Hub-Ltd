## 4. Design system (web)

**Grid.** 12 columns, 1200px max content width, 24px gutter; 16px side padding under 768px. Breakpoints 360 · 768 · 1024 · 1280.

**Rhythm.** 8px spacing scale. Section padding 120px desktop / 72px mobile. Sections alternate paper and white, with ink bands for emphasis (H-07, CTA, footer).

**Surfaces.** 1px stone hairlines, 4px radii (restrained — premium, not bubbly), two-layer soft shadow on cards, brass 1px rule as the recurring accent.

**Motion.** 200–300ms fades and 12px rises on scroll entry; header compaction; all of it off under `prefers-reduced-motion`.

**Colour** — the round-2 identity (ink, indigo, brass, paper); applies whichever logo the client picks.

## 4c. Build standards — the bar for launch

**Accessibility**

- Skip-to-content link; one H1 per page; lang="en-GB"
- Visible focus ring on everything interactive: 2.5px amber outline, 3px offset
- Touch targets ≥ 44 × 44px
- Mega menu: Enter/Space opens, arrow keys move, Esc closes and returns focus
- Mobile drawer traps focus while open; body scroll locked
- Before/after slider is a labelled range input — keyboard operable
- Form: visible labels, errors tied to fields with aria-describedby, announced on submit
- Alt text written per image, not generated; decorative images get empty alt
- All motion off under prefers-reduced-motion

**Performance budget**

- Home page ≤ 1 MB on first load; images above the fold ≤ 200 KB
- Two font families, WOFF2 subsets, ≤ 120 KB total; the two critical files preloaded; font-display: swap
- JavaScript ≤ 30 KB, no framework; analytics only after consent
- Responsive images with srcset and explicit width/height on every img
- LCP < 2.0s on 4G · CLS < 0.05 · INP < 200ms · Lighthouse ≥ 95 mobile on all four scores

**SEO, technical**

- Canonical on every page: https apex, no trailing slash, no index.html
- Open Graph and Twitter cards on every content page, 1200 × 630 image
- sitemap.xml with lastmod; robots.txt points to it; /thank-you and /404 noindex
- LocalBusiness schema: address, geo, telephone, openingHours, areaServed, sameAs (socials)
- Phone links tel:+254711128736; WhatsApp links https://wa.me/254711128736?text=… (no plus, no spaces)
- Search Console verified by DNS TXT; Google Business Profile linked both ways

**Security and hosting**

- .htaccess: HTTPS and www → apex 301s, clean URLs, gzip, long cache on versioned assets
- Headers: CSP default-src self (Google Analytics allowed only for the consented script), HSTS, X-Content-Type-Options, Referrer-Policy, Permissions-Policy, frame-ancestors none
- Form handler: honeypot, minimum fill time, per-IP rate limit, server-side validation, authenticated SMTP to info@
- No third-party embeds: static map image, no iframes
